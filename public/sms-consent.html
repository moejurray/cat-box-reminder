Cat Box Reminder — SMS Consent

This is a private household SMS reminder system used to remind household members when the cat box needs cleaning.

How consent is collected

Only invited household members are added to the reminder list. Each person receives a private invitation link and must explicitly agree to receive SMS text reminders before the Cat Box Reminder system will send messages to that number.

Program purpose

After the cat box is marked cleaned, a shared 36-hour timer begins. When the timer expires, opted-in household members receive an SMS reminder during the allowed sending window. When any recipient confirms that the box has been cleaned, the shared timer resets.

Opt-out and help

Recipients may reply STOP at any time to stop receiving messages and HELP for assistance. Phone numbers are not shared or sold. This is a private, non-commercial household reminder system and does not advertise or promote any product or service.
